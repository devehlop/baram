# Промо «Барам»: ролик и карусель

Ролик для сторис и клипов и карусель для ленты VK и Telegram. Сделано на [Remotion](https://www.remotion.dev): каждый слайд — React-компонент, анимация считается по кадрам.

| Что | Композиция | Размер | Куда |
| --- | --- | --- | --- |
| Ролик 22 с | `PromoStory` | 1080×1920 (9:16) | сторис Telegram и VK, клипы |
| Ролик 22 с | `PromoFeed` | 1080×1350 (4:5) | лента VK и Telegram |
| 8 картинок | `Card1` … `Card8` | 1080×1350 (4:5) | карусель в посте |

## Запуск

Нужен Node.js 22.

```bash
cd marketing/promo
npm install
```

```bash
npm run studio
```

Откроется Remotion Studio в браузере: там видно все слайды, можно перематывать и смотреть тайминг.

Готовые файлы попадают в `out/` (в git не идёт):

```bash
npm run render:story
```

```bash
npm run render:karusel
```

## Как устроено

- `src/Scenes.tsx` — восемь слайдов: заголовок, текст, иллюстрация. **Тексты правятся здесь.**
- `src/Slide.tsx` — общий макет: логотип, иллюстрация, текст, точки, узор. Размеры для 9:16 и 4:5 — в `layoutOf`.
- `src/Promo.tsx` — порядок слайдов, длительность каждого (`DUR`, в кадрах при 30 fps) и переходы.
- `src/Ornament.tsx` — полоса тюльпанов внизу, нарисована кодом.
- `src/theme.ts` — цвета, шрифт Onest, имя бота и канала.
- Слайд 2 (телефон со списком рейсов) нарисован кодом, на слайде 5 надписи «Сел в машину» и «Доехали» тоже накладываются кодом.

## Иллюстрации

Сгенерированы в Gemini по логотипу, лежат в `public/img/` с прозрачным фоном.

| Слайд | Файл |
| --- | --- |
| 1 Обложка | `s1-towns.png` |
| 3 Бронь в 3 нажатия | `s3-tap.png` |
| 4 Водители проверены | `s4-shield.png` |
| 5 Спокойно за родных | `s5-chat.png` |
| 6 Платите водителю | `s6-pay.png` |
| 7 Нет подходящего рейса | `s7-bell.png` |
| 8 Едем! | `s8-road.png` |

Заменить картинку: сгенерировать новую на кремовом фоне, убрать фон скриптом и положить под тем же именем.

```bash
python3 tools/key.py новая-картинка.jpg public/img/s3-tap.png
```

Скрипт делает кремовый фон прозрачным и обрезает края. Если у новой картинки другие пропорции, поправьте `artAspect` у слайда в `src/Scenes.tsx`.

На слайде 5 надписи стоят точно в пузырях этой картинки. Для другой картинки поправьте их положение в `ChatOverlay`.
