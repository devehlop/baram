# Барам — дизайн-спецификация для разработки

> «Барам» по-татарски — «еду». Стиль «Калфак и сурпан»: цвета и узоры татарского и чувашского народного искусства поверх простого, крупного интерфейса.
> Живые макеты: холст «Барам — дизайн Mini App» (ряд **«Народный стиль»** — финальный стиль; ряды выше — структура всех экранов).
> Рядом с этим файлом: `theme.css` (токены), `Ornaments.tsx` (логотип, узоры, розетка).

## 0. Главное для агента

1. **Финальный стиль — «Народный»** (FolkStyle, FolkOnboarding, FolkHome, FolkResults). Остальные экраны на холсте (жёлтые) задают **структуру и тексты**; при вёрстке перекрась их по таблице соответствия из §2.3.
2. Стек из ТЗ: React + Vite + Telegram Mini Apps SDK + Telegram UI. Цвета и шрифт **наши**, не тема Telegram: компоненты Telegram UI переопределяй через CSS-переменные из `theme.css`.
3. Не выдумывай новые цвета, отступы и радиусы — только токены. Если чего-то не хватает — добавь токен в `theme.css`, а не хардкод.
4. Узор — **только декоративная полоса по краю** (шапка, низ карточки). Никогда под текстом, кнопками, полями ввода.
5. Доступность — обязательна: аудитория включает пожилых. Минимум 16 px текст, 48 px высота нажимаемого, контраст 4.5:1.

## 1. Принципы интерфейса (из ТЗ, влияют на вёрстку)

- Один экран — один вопрос. Заголовок вопроса крупно (28–32 px), под ним варианты-карточки.
- Кнопки вместо ввода. Печатать только адрес и комментарий.
- Простые слова: «Найти поездку», «Отправить посылку», «Мои поездки», «Помощь», «Еду с ним», «Всё верно», «Исправить».
- На каждом шаге: кнопка «Назад» (иконка, 48×48) слева и «В начало» справа; прогресс «Шаг N из 7» + полоса.
- Не больше 3–4 крупных кнопок на экране. Главная кнопка внизу экрана, во всю ширину.
- «Позвонить водителю» / «Позвонить диспетчеру» доступны на экранах поездки.
- Перед бронью — экран-итог (Summary) с «Всё верно» и «Исправить».

**Запрещено:** белый текст на `--c-gold`; красный текст на зелёном; любой текст поверх узора.

### 2.2 Типографика

Шрифт **Onest** (Google Fonts, кириллица), веса 400/500/600; иерархия — размером и цветом. 800 только у логотипа. Фолбэк `system-ui, sans-serif`.

| Роль | Размер / вес / межстрочный |
|---|---|
| Логотип «барам» | 36–72 / 800, letter-spacing −0.035em, всегда строчными |
| Вопрос шага (H1) | 32 / 600 / 1.1 |
| Заголовок экрана | 26 / 600 |
| Время в карточке рейса | 30 / 600 |
| Цена в карточке | 24 / 600 |
| Заголовок карточки | 18–21 / 600 |
| Кнопка главная | 18 / 600 |
| Основной текст | 17 / 400 / 1.4 |
| Вторичный текст | 15 / 400 |
| Метка над карточкой | 15 / 600, обычный регистр, без трекинга |
| Минимум | 15 везде |

### 2.3 Соответствие «первые макеты → народный стиль»

| На жёлтых макетах | Делать так |
|---|---|
| Жёлтая главная кнопка `#FFCC33` | `--c-red`, текст белый |
| Чёрная карточка «частый маршрут»/итог цены | `--c-green`, кнопка внутри — `--c-gold` с текстом `--c-ink`, внизу полоса тюльпанов |
| Зелёная «Всё верно» `#157A4C` | `--c-green` |
| Жёлтая выбранная карточка / рамка 3px `#15171C` | рамка 3px `--c-red` |
| Чип `#FFF3CC` (доплата) | `--c-gold-soft` + текст `#5A3F0A` |
| Фон `#F5F3EF` | `--c-canvas` |
| Чипы `#F0ECE4` | `--c-surface-2` |
| Бейдж «Вы уже ездили» (зелёный чип) | розетка 20px + текст `--c-red-ink` «Надёжный водитель · вы уже ездили» |
| Логотип: жёлтый квадрат | красный квадрат, белая стрелка |

### 2.4 Отступы, радиусы, размеры

- Все отступы и gap — кратны 4 px (16, 20, 12, 8…); 10/14/18 не использовать.
- Сетка 4 px. Боковые поля экрана **16 px**. Расстояние между блоками 12–16 px, внутри карточки 12–14 px.
- Радиусы: кнопка 16–18, карточка 20–24, плитка меню 24, чип 10, бейдж 8, иконка-квадрат 14–18, кнопка «Назад» 16.
- Высоты: главная кнопка **60**, кнопка в карточке 54–56, малая кнопка 44, поле ввода 48, кнопка «Назад» 48×48, плитка меню 140, карточка-вариант ≥ 72.
- Иконки: линейные, stroke 2 (2.4 для «Назад»), скругление концов, 24–34 px. Можно взять lucide-react и выставить `strokeWidth`. Без эмодзи в интерфейсе.
- Тени не используем: глубина — цветом фона (холст → белая карточка → зелёная карточка).

## 4. Узоры — правила

- **Чувашская полоса (`ChuvashBand`)** — ромб с крючками (основной мотив чувашской вышивки). Варианты: на холсте (красный ромб, чёрная сердцевина) и инверсный (красная лента, светлый ромб). Где: верх главной (20px, инверсный), под шапкой приветствия (24px), низ первой карточки рейса (14px).
- **Татарская полоса (`TulipBand`)** — тюльпан, главный мотив татарского орнамента: золотые лепестки, красная сердцевина, листья на зелёном. Где: шапка приветствия (72px), низ зелёной `RouteCard` (28px).
- **Розетка (`Rosette`)** — восьмиконечная, общий для обоих народов знак. Где: значок «Надёжный водитель», маркер подтверждённой поездки, пустые состояния (64–88px).
- На экране не больше **двух** узорных полос. На экранах шагов анкеты (OptionCard) узоров нет вовсе — только на главной, приветствии, карточках рейсов, итогах и экранах статуса.
- Узоры — SVG `<pattern>`, тянутся на любую ширину. `aria-hidden="true"`.

## 5. Экраны

Структура и тексты — с холста. Отмечено, где есть готовый народный макет.

**Пассажир:** Первый запуск ★ · Главная ★ · Шаг 1 «Кто едет?» · Шаг 2 «Откуда» (с подсказкой доплаты деревни — чип/плашка gold-soft) · 3 «Куда» · 4 «Когда» · 5 «Сколько вас» · 6 «Багаж» · 7 «Комментарий» · Список рейсов ★ · Итог · Поездка в пути · Посылка: размер (сетка 2×2 OptionCard + чипы-галочки «Хрупкое / Не переворачивать / В холоде»).
**Водитель:** Главная водителя (карточка новой брони: Принять — `confirm`, Отказать — `outline`; зелёная карточка ближайшего рейса; 4 плитки) · Мои рейсы / порядок объезда (нумерованные остановки, «В навигатор», «Позвонить», внизу «Выехал»).

★ — есть макет в народном стиле; остальные строить по таблице §2.3.

## 6. Тексты и язык

- Интерфейс по-русски. Татарский/чувашский — только приветствия как деталь: «Сәлам · Салам» на первом экране, «Исәнмесез,» над именем на главной.
- Не писать в интерфейсе, для каких народов или регионов сервис.
- Логотип — всегда «барам» строчными.

## 7. Чат-бот

Кнопки Telegram в чате не окрашиваются — стиль бота это: аватар (логотип на красном), тексты по §1 и §6, обложки каналов направлений с `TulipBand`/`ChuvashBand`. Порядок сообщений шага: метка «Шаг N из 7», вопрос, варианты по одной кнопке в ряд, последний ряд «‹ Назад» | «В начало».

## 8. Telegram Mini App

- При запуске: `setHeaderColor('#F6EFE2')`, `setBackgroundColor('#F6EFE2')`, `setBottomBarColor` в цвет холста. Используй `BackButton` Telegram в дополнение к нашей «Назад».
- Тёмная тема в MVP **не делается**: фиксируем светлую палитру. (Открытый вопрос — отдельная задача.)
- Главную кнопку шага можно отдать Telegram `MainButton` с цветом `--c-red` и белым текстом.

## 9. Чек-лист готовности экрана

- [ ] Только токены из `theme.css`.
- [ ] Текст ≥ 15 px (метки ≥ 13), нажимаемое ≥ 48 px, главная кнопка 60 px.
- [ ] «Назад» и «В начало» на шагах; «Позвонить» на экранах поездки.
- [ ] Не больше 2 узорных полос, узор не пересекается с текстом.
- [ ] Все кнопки — `<button>`, у иконок-кнопок `aria-label`.
- [ ] Проверено на ширине 360 px и 430 px.
