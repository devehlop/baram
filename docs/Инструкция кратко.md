# «Барам» — кратко

Telegram-бот попутчиков **Буинск ⇄ Казань**. Подробно — [Инструкция.md](Инструкция.md).

## Старт

`/start` → «Я пассажир» или «Я водитель» → имя → номер **кнопкой** «Поделиться номером» → меню.

Команды: `/start` · `/menu` · `/find` поиск · `/trips` поездки · `/board` доска · `/help` · `/privacy` · `/id` ваш Telegram ID.

## Пассажир

1. **🚗 Найти поездку** → направление → день → рейс → откуда → куда.
2. В карточке проверьте места, багаж, ребёнка, «кто едет» → **Забронировать**.
3. Водитель нажмёт «Принять» → придут госномер и телефон.
4. За 3 часа ответьте «Да, еду». После поездки поставьте звёзды.

Нет рейса → **Оставить заявку**: её увидят водители, через 30 мин без ответа — админ.
Едет другой человек → «👤 Едет» → «Другой человек».
Крупный багаж → предоплата 600 ₽ только по реквизитам из бота.
**🔁 Мои поездки**: «Обратно», «Повторить», отмена, жалоба.

## Водитель

1. **Анкета** (10 вопросов, фото машины, права, СТС, реквизиты) → «Отправить на проверку». До одобрения рейсы нельзя.
2. **➕ Выложить рейс** (7 шагов) или «Повторить: …». Цена едина — 800 ₽, её ставит админ.
3. Приходит бронь → **Принять** / **Отказать**.
4. В день поездки: **Выехал** → «Буду через N мин» → **Забрал** → **Доехали**.
5. **+ Занято по телефону**, **🔔 Заявки** («Беру»), **📣 Поделиться рейсом**.

Лимиты: до 2 рейсов в сторону в день, без дублей и пересечений, не дальше 7 дней вперёд.

## Админ

`/id` → число в `ADMIN_IDS` в `.env` → перезапуск → кнопка **🛠 Админ**.

- Проверка водителей: одобрить / отклонить / запросить фото
- Заявки без водителя → «Предложить»
- Жалобы: в работу → заметка → закрыть
- Найти пользователя: блокировка, «Проверен», бронь через админа
- Настройки: цена, сроки, пороги (действуют сразу)
- Деревни · «Откуда приходят» · канал «Рейсы на <день>» (бот — админ канала)

## Канал

Сводный пост «Рейсы на <день>» с рейсами дня. Обновляется сам, у рейсов со свободными местами есть ссылка «забронировать».

## Правила

| | |
| --- | --- |
| Свободная отмена | больше 4 ч до выезда |
| «Едете?» | за 3 ч |
| 3 поздние отмены или неявки за месяц | бронь только через админа |
| Рейтинг виден | с 3 оценок |

## Mini App

Кнопка «Барам» слева от поля ввода: поиск, бронь, поездка, у водителя — брони и рейсы. Анкета, жалобы и админ — только в чате.

## Если что-то не так

Бот молчит → проверить запуск и `BOT_TOKEN` · нет «🛠 Админ» → ID в `ADMIN_IDS` · рейс не выкладывается → анкета на проверке или сработал лимит.

Проверка сценариев — [CHECKLIST.md](CHECKLIST.md) · сервер — [DEPLOY.md](DEPLOY.md).
