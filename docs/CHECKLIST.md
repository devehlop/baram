# Как проверить в тестовом боте

Нужны два аккаунта Telegram: один — пассажир, второй — водитель (и он же админ). Удобно взять свой телефон и телефон близкого человека.

Перед проверкой: бот запущен, ваш ID вписан в `ADMIN_IDS`.

## Этап 1. Каркас

- [ ] `/start` — бот здоровается и спрашивает «Вы едете как пассажир или вы водитель?».
- [ ] `/id` — бот показывает ваш Telegram ID.

## Этап 2. Регистрация и роли

- [ ] Пассажир: «Я пассажир» → имя → кнопка «Поделиться номером» → появилось меню из больших кнопок.
- [ ] Номер текстом бот не принимает — только кнопкой.
- [ ] Водитель: «Я водитель» → имя → номер → анкета из 10 вопросов → «Отправить на проверку».
- [ ] В анкете работают «‹ Назад» и «Исправить».
- [ ] Админу пришли фото машины и анкета с кнопками «Одобрить», «Отклонить», «Запросить фото заново».
- [ ] «Запросить фото заново» → водитель присылает фото → анкета снова у админа.
- [ ] «Одобрить» → водитель получил сообщение и меню водителя.
- [ ] Пока анкета не одобрена, «Выложить рейс» отвечает, что анкета на проверке.

## Этап 3. Рейсы водителя

- [ ] «Выложить рейс» → 8 шагов → итог → «Выложить».
- [ ] Второй раз: «Повторить: …» → день → «Выложить».
- [ ] Тот же маршрут в то же время ещё раз — бот не даёт (дубль).
- [ ] Встречный рейс через час — бот не даёт (не хватает времени на дорогу).
- [ ] «Мои рейсы» → рейс → «+ Занято по телефону» → 2 → свободных мест стало меньше.
- [ ] Бронь по телефону → «Добавить имя и телефон» → отправить контакт из телефонной книги.
- [ ] «Отменить рейс» → рейс пропал из «Моих рейсов».

## Этап 4. Поиск и бронь

- [ ] Пассажир: «Найти поездку» → 7 вопросов → список рейсов → «Всё верно».
- [ ] В списке рейсов нет госномера; после «Принять» у водителя — госномер и телефон пришли пассажиру.
- [ ] Поиск на время, когда рейса нет, — бот показывает «Ближайшие рейсы».
- [ ] Рейсов нет совсем → «Оставить заявку» → водителю пришла заявка → «Беру» → пассажир получил бронь.
- [ ] «Кто едет?» → «Другой человек» → имя, телефон, «Подросток» → водитель видит и пассажира, и заказчика.
- [ ] Багаж «Много» → после «Принять» пассажиру пришли реквизиты водителя и предупреждение о мошенниках → водитель жмёт «Предоплата получена».
- [ ] После брони бот предлагает запомнить адрес; в следующем поиске адрес — первой кнопкой.
- [ ] «Мои поездки» → поездка → «Обратно» → бот спрашивает только день и время.

## Этап 5. Уведомления и статусы

- [ ] Выложите рейс на ближайшие 3 часа и забронируйте: в течение минуты пассажиру придёт «Едете сегодня в …?».
- [ ] «Да, еду» → водитель получил «подтвердил поездку».
- [ ] Водитель: «Выехал» → пассажир получил сообщение; «10 мин» → «будет примерно через 10 минут».
- [ ] «Забрал» → если ехал другой человек, заказчик получил «… в машине».
- [ ] «Доехали» → пассажир получил «Поездка завершена».
- [ ] Отмена больше чем за 4 часа — «свободная отмена»; меньше — «поздняя отмена».
- [ ] «Не пришёл» → пассажир получил сообщение.

Чтобы не ждать, сроки можно временно уменьшить: Админ → Настройки.

## Этап 6. Канал

- [ ] Бот — администратор канала; адрес канала задан в Админ → Настройки.
- [ ] После первого рейса в канале появился пост «Рейсы на …».
- [ ] После второго рейса или брони пост обновился, а не продублировался.

## Этап 7. Админ в боте

- [ ] «🛠 Админ» показывает счётчики: проверка водителей, заявки, жалобы, брони.
- [ ] Заявку никто не взял 30 минут → пришла админу → «Предложить» водителю → водитель получил.
- [ ] Пассажир: поездка → «Пожаловаться» → админу пришла жалоба → «Взять в работу» → «Заметка» → «Решить и закрыть».
- [ ] «Найти пользователя» → «Заблокировать» → человек видит «Ваш аккаунт заблокирован».
- [ ] «Бронь только через админа» → бронь этого человека сначала приходит админу.
- [ ] Водителю выдан значок «Проверен» → значок виден в карточке рейса у пассажира.
- [ ] «Настройки» → изменить «Заявка админу через, мин» → новое значение действует сразу.
- [ ] «Деревни» → добавить деревню → у пассажира появилась кнопка «Деревня или село».

## Этап 8. Пилот

- [ ] Бот запущен на сервере: в логе строка «Бот запущен».
- [ ] В папке `backups/` появился файл копии базы.
- [ ] Копия восстанавливается в отдельную базу.

## Рейс в чате попутчиков

Проверка на одном чате перед тем, как пускать в остальные. Нужен рейс на завтра и второй аккаунт «пассажир».

- [ ] После «Выложить рейс» под сообщением две кнопки: «В чат — с телефоном» и «В чат — без телефона».
- [ ] Кнопка открывает выбор чата, текст объявления виден и правится до отправки; ссылка на бота стоит первой строкой.
- [ ] В чате объявление опубликовано от имени водителя и не удалено админом за час и за сутки. Если удалили или забанили — записать, что именно было в тексте.
- [ ] Пассажир нажимает ссылку: видит карточку рейса (без госномера) и «Забронировать место».
- [ ] Новый человек по ссылке проходит регистрацию и сразу попадает на карточку рейса.
- [ ] В брони по ссылке нет вопросов про день и время; отменили рейс по пути — бот честно говорит об этом.
- [ ] Через неделю: сколько броней пришло по ссылкам из чата, сколько водителей нажали кнопку.

## Mini App

Без Telegram, на демо-данных: `npm run miniapp:build`, затем `npm run miniapp:preview` и http://localhost:8080.

- [ ] Главная: приветствие, зелёная карточка «Повторить поездку», четыре плитки, ближайшая поездка.
- [ ] «Найти поездку»: 7 шагов, на каждом «Назад» и «В начало», полоса прогресса.
- [ ] Список рейсов: первая карточка с красной кнопкой и узорной полосой; внизу «Не подошло? Оставить заявку».
- [ ] «Проверьте поездку» → «Всё верно» → экран поездки со статусом «Ждём ответа водителя».
- [ ] «Исправить» → одно поле → снова список рейсов.
- [ ] Экран поездки после подтверждения: номер машины, этапы, «Позвонить водителю», «Отменить бронь».
- [ ] Водитель (`AS=driver npm run miniapp:preview`): карточка новой брони с «Принять» и «Отказать», рейс с порядком объезда, «Выехал».
- [ ] «Выложить рейс»: форма одним экраном; повтор заполнен из прошлого рейса.
- [ ] На ширине 360 px ничего не обрезано и нет горизонтальной прокрутки.

В Telegram (после включения на сервере):

- [ ] В чате с ботом слева от поля ввода есть кнопка «Барам», она открывает Mini App.
- [ ] Бронь, сделанная в Mini App, приходит водителю сообщением в чат, и наоборот: «Принять» в чате меняет статус в Mini App.
- [ ] Незарегистрированный человек видит экран приветствия с кнопкой «Перейти в чат с ботом».
